# corpus/arch/

Architecture tools: interactive and structural pieces of the Recursive Consciousness Architecture (RCA), the
framework the corpus grew out of.

| File | What it is |
|---|---|
| `interactive_cli.py` | An interactive shell for the architecture. |
| `sephirotic_dialogue_mapper.py` | Maps a dialogue onto pathways of the Tree of Life. |
| `framework_aware_observer.py` | Tracks telemetry through four depths (message, analysis, event, meta-trend) in a directed acyclic provenance graph, to find patterns that cross layers. |
| `circular_loop_engine.py` | The "10 = 1" loop as code: Will, Architecture, Analysis and Manifestation in turn, then back to the start, tracking entropy and confidence at each depth. |
| `benchmark_stress_test.py` | A performance and stress test suite. |
| `test_all_tools.py` | The integration runner for this folder. |

Run the integration tests, from this folder:

```bash
python test_all_tools.py
```

These are architecture tools, not among the 24 engines `../test_all_engines.py` counts.
